# 교통비 관리 — UI/UX 설계

---

## 1. 진입 경로

사이드바에 Ledger 서브탭으로 표시된다.

```
📕 가계부
├ 메인          → #ledger
└ 교통비 관리   → #ledger/transit
```

`moduleRegistry.tsx` 변경:
```typescript
ledger: {
  subNav: [
    { key: '',          label: '메인',      icon: '📋' },
    { key: 'transit', label: '교통비 관리', icon: '🚌' },
  ],
}
```

## 3. 탑승 횟수 진행 바

15회 달성 여부를 시각적으로 표현.

```
미달 상태 (11/15):
탑승 횟수  ████████░░░░░░░  11회 / 15회  ⚠️ 4회 더 필요
색상: --warn

달성 상태 (18/15):
탑승 횟수  █████████████░░  18회 ✅ 환급 대상
색상: --ok

초과 달성 표시: 15회 초과분은 진한 색으로 구분
```

## 8. 상태 색상 규칙

| 상태 | 색상 변수 | 아이콘 |
|------|-----------|--------|
| 환급 대상 (15회↑) | `--ok` | ✅ |
| 15회 미달 | `--warn` | ⚠️ |
| 환급 수령 완료 | `--text-muted` | ✅ |
| 환급 예정 | `--primary` | 🕐 |
| 기후동행 이득 | `--ok` | ✅ |
| 기후동행 손해 | `--warn` | ⚠️ |
