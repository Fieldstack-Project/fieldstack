# 세무 준비 지원 기능 (Tax Preparation Support) - Draft

> **상태**: 초안 (Draft) / 외부 전문가(세무사) 검증 및 피드백 반영 필요  
> **최종 업데이트**: 2026-08-16  
> **위치**: Ledger/금융 모듈 내부 기능  
> **역할**: 세금 신고 대행이 아닌 세무 준비 및 자료 정리 보조

---

## 1. 개요

Fieldstack의 세금 관련 기능은 사용자의 수입, 지출, 급여, 원천징수, 증빙자료를 정리하고 예상 세금과 자금 상태를 파악할 수 있게 돕는 **세무 준비 도구**입니다.

Fieldstack은 최종 신고, 세무 판단, 신고 대행을 수행하지 않습니다. 최종 신고와 세무 판단은 사용자 본인 또는 세무사가 처리합니다.

이 문서는 향후 개발자가 금융 모듈 안에서 세무 보조 기능을 설계할 때 참고할 수 있도록 목적, 범위, 책임 경계, 검토 기능을 정리합니다.

---

## 2. 확정 원칙

### 2.1 Fieldstack의 역할

Fieldstack은 사용자와 세무사 사이의 **징검다리이자 세무 준비 도구**입니다.

지원하는 일:
- 예상 세금 계산
- 자금 상태 파악
- 세금 대비 자금 관리
- 관련 자료 정리
- 증빙 누락 확인
- 신고 준비 체크
- 세무사와의 자료 공유

지원하지 않는 일:
- 세금 신고 대행
- 세무대리 업무
- 법률 또는 세무 자문 대체
- 계산 결과를 확정 세액으로 보장

### 2.2 기능 위치

세금 기능은 별도 산업 모듈이 아니라 **Ledger/금융 모듈 내부 기능**으로 구성합니다.

건설현장, ONEPMIS, 매장관리, 급여관리 등 특정 산업이나 업무 형태에 종속되지 않습니다. 향후 별도 업무 모듈이 만들어지는 경우 해당 모듈은 Event Bus 또는 공개 인터페이스를 통해 금융 모듈의 세금 계산, 증빙 분류, 자료 공유 기능을 재사용하는 구조를 권장합니다.

### 2.3 대상 사용자

기본 대상:
- 일반 사용자
- 프리랜서
- 부업 소득이 있는 사용자
- 개인사업자
- 직원을 고용한 개인사업자
- 스트리머 및 크리에이터

기본 범위에서 제외:
- 일반 법인
- 중견·대형 사업자
- 전문 세무/회계 시스템이 필요한 조직

법인 또는 산업별 전문 요구사항은 향후 별도의 사업자용 모듈 또는 산업별 모듈에서 확장하는 방향으로 검토합니다.

## 3. 예상 세금 계산

### 3.1 목적

예상 세금 계산의 목적은 사용자가 현재 수입, 비용, 공제, 원천징수, 부가가치세 관련 상태를 이해하고 필요한 자금을 미리 준비하도록 돕는 것입니다.

계산 결과는 확정 세액이 아니며, 화면과 리포트에는 항상 **예상값**임을 표시해야 합니다.

### 3.2 기준 데이터

계산 기준 데이터는 국세청, 공공데이터포털 등 공식 자료를 기반으로 수집·가공합니다.

검토 대상 기준 데이터:
- 세율
- 공제 기준
- 간이세액표
- 원천징수 기준
- 부가가치세 관련 기준
- 4대보험 연계에 필요한 기준 금액

세법과 세율은 변경될 수 있으므로 계산 로직과 기준 데이터는 버전 관리가 가능해야 합니다.

### 3.3 계산 결과 표시 항목

가능하면 계산 결과에는 다음 정보를 함께 표시합니다.

- 적용 기준 연도
- 사용된 세율 또는 계산 기준
- 기준 데이터 출처
- 데이터 최종 갱신일
- 계산에 포함된 수입 항목
- 계산에 포함된 비용 항목
- 계산에 포함된 공제 항목
- 누락되었거나 확인이 필요한 정보
- 확정 세액이 아니라는 안내

### 3.4 데이터 버전 관리 방향

계획:
- 기준 연도별 세율/공제/간이세액표 데이터를 분리합니다.
- 계산 실행 시 사용한 기준 데이터 버전을 결과에 기록합니다.
- 기준 데이터 출처와 최종 갱신일을 함께 보관합니다.
- 과거 계산 결과를 다시 열 때 당시 기준으로 계산되었음을 확인할 수 있게 합니다.

검토:
- 기준 데이터 자동 갱신 여부
- 수동 검수 후 반영하는 운영 방식
- 공식 데이터가 구조화되어 있지 않은 경우의 가공 절차
- 세무사 또는 전문가 검증 플로우

## 4. 초기 기능 범위

초기에는 다음 영역을 우선 고려합니다.

- 근로소득 관련 예상 세금
- 프리랜서 및 사업소득 관련 원천징수
- 기타소득
- 개인사업자 종합소득세 예상
- 개인사업자 부가가치세 예상
- 직원 급여 및 원천징수 관련 정보
- 필요 시 4대보험 관련 금액 연계
- 수입 및 지출 기반 세금 적립 권장액 계산

위 항목은 신고를 대신하기 위한 기능이 아니라 사용자가 신고 준비 상태와 예상 자금 부담을 확인하기 위한 보조 기능입니다.

## 5. 스트리머 및 크리에이터 수익 관리

스트리머와 크리에이터는 여러 수익원을 합쳐 관리할 수 있어야 합니다.

검토 대상 수익원:
- YouTube 광고 수익
- 플랫폼 구독 및 후원
- 치지직 등 스트리밍 플랫폼 수익
- 광고 및 협찬
- 외주
- 기타 개인사업 또는 프리랜서 수익

계획:
- 수익원을 플랫폼, 계약, 프로젝트, 통화 기준으로 구분할 수 있게 합니다.
- 외화 수익은 환율 기준일과 적용 환율을 함께 기록합니다.
- 콘텐츠 제작 비용은 거래 항목과 증빙자료를 함께 관리합니다.
- 영세율, 면세, 과세 여부 등은 사용자 확인 또는 세무사 확인이 필요한 상태로 표시할 수 있게 합니다.

## 6. 세무사와의 자료 공유

Fieldstack은 사용자가 세무사에게 자료를 전달하는 과정을 쉽게 만드는 기능을 제공할 수 있습니다.

계획:
- 사용자가 특정 기간의 세무 자료 공유 페이지를 생성합니다.
- 공유 페이지는 만료일이 있는 링크로 접근합니다.
- 세무사는 공유 페이지에서 필요한 자료를 확인하거나 다운로드합니다.
- 사용자는 공유 범위, 접근 기간, 다운로드 가능 여부를 관리합니다.

공유 가능한 자료:
- 매출 자료
- 매입 자료
- 비용 및 경비 자료
- 급여 내역
- 원천징수 관련 자료
- 각종 영수증 및 증빙
- 거래내역
- 세금 계산 참고자료
- 기타 신고에 필요한 파일

자료 상태 표시:
- 준비 완료
- 자료 누락
- 확인 필요
- 추가 자료 필요

검토:
- 파일별 선택 다운로드
- 전체 자료 일괄 다운로드
- 세무사 코멘트 또는 요청사항 기록
- 공유 페이지 접근 로그
- 민감정보 마스킹 및 다운로드 감사 기록

## 7. 신고자료 체크 기능

신고 시기에 맞춰 필요한 자료를 체크하는 기능을 검토합니다.

예시:
- 종합소득세 신고 준비 시 현재 Fieldstack에 등록된 수입, 지출, 증빙, 원천징수 자료를 기준으로 필요한 자료를 분류합니다.
- 준비 완료, 자료 누락, 확인 필요 상태를 표시합니다.
- 누락된 항목은 사용자가 직접 보완하거나 세무사에게 확인할 수 있도록 안내합니다.

이 기능의 목적은 신고를 대신하는 것이 아니라 **자료 누락을 줄이는 것**입니다.

## 8. 데이터 구조 검토 방향

아래 구조는 구현 확정 스키마가 아니라 향후 설계를 위한 검토 기준입니다.

### 8.1 세무 메타데이터

가계부 항목(`ledger_entries`)과 연결되는 세무 메타데이터를 별도 구조로 관리하는 방식을 검토합니다.

검토 필드:
- 거래 항목 ID
- 세무상 분류
- 비용 인정 여부
- 증빙 종류
- 부가가치세 관련 금액
- 과세/면세/영세율 구분
- 확인 상태
- 확인자 또는 확인 출처

### 8.2 원천징수 정보

인건비, 프리랜서 지급, 기타소득 지급 등 원천징수 대상 거래는 별도 정보로 관리하는 방식을 검토합니다.

검토 필드:
- 수령인 정보
- 지급 총액
- 원천징수액
- 실지급액
- 지급일
- 적용 세율
- 적용 기준 연도
- 개인정보 암호화 여부

주민등록번호, 사업자등록번호 등 민감정보가 필요한 경우 저장 최소화, 암호화, 접근 권한, 감사 로그를 별도 보안 기준으로 설계해야 합니다.

## 9. UI/UX 원칙

세금 화면은 계산기보다 **준비 상태와 누락 정보**를 명확히 보여주는 방향을 우선합니다.

원칙:
- 계산 결과에는 항상 예상값 표시를 포함합니다.
- 적용 기준 연도와 기준 데이터 출처를 사용자가 확인할 수 있게 합니다.
- 누락 정보와 확인 필요 항목을 결과와 함께 표시합니다.
- 세무 판단처럼 보이는 단정형 문구를 피합니다.
- "신고 완료", "대리 신고", "확정 세액 보장"처럼 오해될 수 있는 표현을 사용하지 않습니다.

참고:
- `https://gosoyeon00.github.io/tax/`는 세금 계산 화면 구성, 입력 흐름, 항목 분류를 참고할 수 있습니다.
- 해당 사이트의 구현 또는 계산 로직을 복제하지 않습니다.
- 실제 계산 기준은 국세청 및 공식 자료를 기반으로 별도 구현합니다.

## 10. 향후 확장

향후 별도 모듈에서 금융·세금 기능을 호출하는 구조를 검토합니다.

예시:
- 급여관리 모듈: 급여 내역과 원천징수 정보를 금융 모듈에 전달
- 매장관리 모듈: 매출/매입 자료를 금융 모듈에 전달
- 프로젝트·외주 모듈: 계약 수익, 외주 비용, 세금계산서 자료를 금융 모듈에 전달

연동 원칙:
- 직접 모듈 내부 테이블을 참조하지 않습니다.
- Event Bus 또는 공개 인터페이스를 사용합니다.
- 세무 계산 기준 데이터는 금융 모듈에서 일관되게 관리합니다.
- 산업별 모듈은 도메인 데이터를 제공하고, 금융 모듈은 공통 세무 준비 기능을 담당합니다.

## 11. 전문가 검증 필요 항목

아래 항목은 세무사 또는 관련 전문가 피드백 후 확정합니다.

1. 근로소득, 사업소득, 기타소득별 예상 계산 범위
2. 원천징수 예외 케이스와 세율 변경 처리
3. 부가가치세 입력/집계 방식
4. 종합소득세 예상 계산에서 공제 항목 입력 범위
5. 4대보험 금액 연계 범위
6. 세무사 공유용 엑셀/PDF/ZIP 자료 포맷
7. 크리에이터 외화 수익 및 영세율 증빙 관리 방식
8. 민감정보 저장 최소화 및 암호화 기준

---

## 12. 요약

Fieldstack의 세금 기능은 신고를 대신하는 서비스가 아닙니다.

Fieldstack은 사용자가 수입, 지출, 급여, 원천징수, 증빙자료를 정리하고 예상 세금과 자금 상태를 파악한 뒤, 필요할 경우 세무사에게 자료를 전달하기 쉽게 만드는 **세무 준비 및 보조 도구**를 목표로 합니다.
