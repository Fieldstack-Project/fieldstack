---

## 1. 개요
Fieldstack의 가계부(Ledger) 데이터를 기반으로 개인사업자, 프리랜서, 유튜버/스트리머의 세무 신고 기초 자료를 생성하고 원천세 납부 일정을 관리하는 모듈입니다.

## 2. 핵심 설계 원칙
1. **증빙 중심 기록**: 적격증빙(카드, 현금영수증)뿐 아니라 경조사비, 계좌이체 등 비적격증빙의 소명 자료를 체계화합니다.
2. **원천세 자동 계산**: 3.3%(사업소득), 8.8%(기타소득) 등 복잡한 세율 계산을 자동화하여 실지급액 관리를 돕습니다.
3. **크리에이터 특화**: 외화 수익(영세율), 방송 장비/소품 비용 처리 등 1인 미디어 환경에 최적화된 분류를 제공합니다.

---

## 3. 데이터 구조 (Schema)

### 3.1 세무 메타데이터 (`ledger_tax_details`)
가계부 항목(`ledger_entries`)과 1:1 또는 1:N으로 연결되어 세무 정보를 저장합니다.

| 필드명 | 타입 | 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | 고유 식별자 | PK |
| `entry_id` | `UUID` | 가계부 항목 ID | FK (ledger_entries) |
| `tax_category` | `string` | 세무상 계정과목 | 접대비, 복리후생비, 소품비 등 |
| `is_deductible` | `boolean` | 비용 인정 여부 | 사용자/AI 판단 |
| `evidence_type` | `enum` | 증빙 종류 | 카드, 현금영수증, 청첩장, 계좌이체 등 |
| `vat_amount` | `number` | 부가세 금액 | **[TBD]** 분리 입력 필요성 확인 중 |

### 3.2 원천세 정보 (`withholding_tax_records`)
인건비 지급 시 발생하는 세금 정보를 관리합니다.

| 필드명 | 타입 | 설명 | 비고 |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | 고유 식별자 | PK |
| `recipient_name` | `string` | 수령인 성함 | 암호화 권장 |
| `recipient_id_no` | `string` | 주민/사업자 번호 | **필수/암호화 저장** |
| `gross_amount` | `number` | 세전 금액 | 원천징수 전 전체 금액 |
| `withheld_tax` | `number` | 원천징수액 | 3.3% / 8.8% 등 자동 계산 |
| `net_amount` | `number` | 실지급액 | 통장 이체 금액 |
| `payment_date` | `date` | 실제 지급일 | 신고일 산정 기준 (익월 10일) |

## 4. 유튜버/스트리머(크리에이터) 특화 기능

### 4.1 수익 관리 (Income)
- **외화 수익(USD) 처리**: 구글 애드센스 등 외화 입금 시 환율 API 연동을 통한 원화 환산 기록.
- **영세율 증빙**: 송금 확인증 등 영세율 적용을 위한 증빙 이미지 첨부 필드 제공.

### 4.2 비용 처리 (Expense)
- **방송 소품 관리**: 게임 타이틀, 의상, 음식 등 방송 콘텐츠와 연관된 지출의 '비용 인정' 가이드라인 UI 제공.
- **프로젝트별 손익**: 특정 영상/콘텐츠 프로젝트 태그를 통해 투자 대비 수익(ROI) 분석 지원.
